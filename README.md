# 📚 StudyNook – Quiet Study Room & Space Booking Platform

StudyNook is a modern full-stack web application designed to help students, researchers, and remote professionals discover, schedule, and host quiet study spaces with real-time slot validation.

🔗 **Live Deployment:** https://studynook-client-kappa.vercel.app

---

## ✨ Key Features

* **Flexible Authentication:** Integrated email/password authentication along with one-click Firebase Google Sign-In with persistent session handling.
* **Smart Conflict-Free Slot Booking:** Automated date and hourly time-slot conflict detection that prevents overlapping room reservations.
* **Workspace Hosting Dashboard:** Authorized users can list, modify, track, or remove their own study rooms with custom amenities and pricing.
* **Reservation Lifecycle Management:** Users can monitor confirmed reservations and cancel future study sessions anytime directly from their bookings dashboard.
* **Dynamic Search & Filtering:** Instant live filtering by title, floor, rate ranges, and essential amenities (Wi-Fi, Whiteboard, AC, Power Outlets).
* **Responsive Scholar-Centric UI:** Modern, distraction-free interface built using Tailwind CSS and Lucide React icons, fully optimized across desktop and mobile screens.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS/Hero UI/
* **Authentication:** Firebase Auth & JWT
* **Icons:** Lucide React
* **Notifications:** React Hot Toast
* **Deployment:** Vercel
